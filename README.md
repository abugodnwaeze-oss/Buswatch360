# 🚌 BusWatch360

**BusWatch360** is a smart school bus management and tracking system designed to help schools, parents, and transport administrators improve the safety, visibility, and efficiency of student transportation.

The system enables schools to manage buses, drivers, students, attendance, and live vehicle tracking from a centralized dashboard while keeping parents informed in real time.

---

# 🚀 Vision

To become Africa's leading intelligent school transportation platform, giving parents peace of mind while helping schools manage transportation safely and efficiently.

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/abugodnwaeze-oss/Buswatch360.git
```

Open the project:

```bash
cd Buswatch360
```

Install dependencies:

```bash
npm install
```

Run the server:

```bash
node server.js
```

Open:

```
http://localhost:3000
```
